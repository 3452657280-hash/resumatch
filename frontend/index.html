ℹ️ 关于 ResuMatch

ResuMatch 是一个基于 Agent 的简历匹配 & 智能分析系统，采用通义千问（DashScope API）+ ChromaDB 向量检索技术栈，通过通义千问大模型对简历与职位描述进行深度匹配分析。

版本: v0.2.0
技术栈: Python / FastAPI / ChromaDB / Qwen / PyMuPDF
