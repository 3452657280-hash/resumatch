ℹ️ 关于 ResuMatch

📖 系统简介

ResuMatch 是一个基于 自研 Agent 框架 的简历匹配 & 智能分析系统，采用通义千问大模型 + ChromaDB 向量检索技术栈，通过两阶段 Agent 流程（关键词提取 → 并行搜索 → LLM 评分 + 自我检查）对简历与职位描述进行深度匹配分析。

🛠️ 自研 Agent 框架说明

自研 Agent 框架 是指 ResuMatch 的 Agent 匹配器（services/matcher.py）完全自主实现，不依赖 LangChain、AutoGPT 等第三方 Agent 框架。

架构特点：
• 两阶段流程：第一阶段用 LLM 从 JD 中提取关键词，第二阶段用这些关键词并行搜索 ChromaDB，再通过 LLM 综合评分 + 自我检查
• 原生 ChromaDB：使用原生 Python 客户端操作向量数据库，中文友好文本分块器替代 LangChain 的 RecursiveCharacterTextSplitter
• 轻量 LLM 接入：纯 httpx 调用 DashScope 的 OpenAI 兼容接口，无 SDK 依赖
• 每次匹配仅调 2 次 LLM，兼顾速度与质量
